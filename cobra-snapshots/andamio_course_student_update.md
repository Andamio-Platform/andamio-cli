## andamio course student update

Update assignment evidence

### Synopsis

Update the evidence for your assignment commitment.

Examples:
  andamio course student update --course-id <id> --module-code 101 --evidence "https://github.com/..."

```
andamio course student update [flags]
```

### Options

```
      --course-id string       Course ID (required)
      --evidence string        Evidence text or URL (Markdown supported)

  -h, --help                   help for update
```
